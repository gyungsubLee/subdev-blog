# 기존 글의 Markdown 표시 수정

2026-10-23에 공통 변환기와 표시 설정을 수정했다. 기존 글 3,032개를 다시 생성했다.
본문 1,856개와 요약 415개가 바뀌었다. 글 ID, 제목, 계층과 날짜는 유지했다.

## 수정한 내용

- 강조·기울임·밑줄·취소선은 안전한 HTML 태그로 변환한다. 공백·괄호·한글 조사가 붙어도 서식을 유지한다.
- 인접한 코드 조각은 표시 서식이 같으면 합친다. 코드 안의 백틱과 문장부호를 보존한다.
- 토글 제목의 강조·밑줄·코드·링크를 표시한다.
- 원본 텍스트의 줄바꿈을 보존한다. 표의 여러 줄 코드에도 같은 규칙을 적용한다.
- 수식은 KaTeX로 표시한다. 일반 텍스트의 달러 기호와 수식 원본은 구분한다.
- HTML 정리와 위험한 URL 차단을 유지한다. KaTeX의 링크·HTML 매크로를 허용하지 않는다.
- 목차에서 HTML 태그와 엔터티가 노출되는 문제를 수정했다.
- 요약의 숫자 엔터티를 올바르게 해석한다. 잘못된 엔터티가 전체 변환을 중단하지 않는다.
- 원본 보관 폴더의 현재 자산 경로를 검사에서 읽는다. 웹 자산의 기존 URL은 유지한다.

## 기존 글 반영

저장된 Notion 블록과 자산 정보를 재사용했다. 원본 보관본과 첨부 파일은 수정하지 않았다.
다음 명령은 현재 블록 원본으로 웹 본문을 다시 생성한다.

```sh
node scripts/repair-markdown.mjs
node scripts/prepare-site.mjs
```

본문 교체는 임시 파일과 `rename`을 사용한다. 글 메타데이터가 바뀌면 교체를 중단한다.
같은 원본으로 다시 실행하면 변경 수는 `0`이다.

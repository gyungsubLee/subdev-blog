# 구조 변경 커밋 검증

커밋할 파일만 분리한 사본에서 전체 검사 468개가 모두 통과했다.
작업 트리에 남은 테마, 버튼, 삭제 기능의 후속 수정은 포함하지 않았다.
다른 작업이 이미 커밋한 파일은 HEAD 기준으로 새 경로에 이동했다.
빌드와 TypeScript도 같은 사본에서 확인했다. 독립 검토의 마지막 판정은 통과다.

커밋용 사본을 만드는 과정에서 HTML 속성 src를 경로로 치환한 오류를 발견했다.
해당 사본과 스테이징만 수정했다. 실제 작업 트리의 제품 파일은 이 오류의 영향을 받지 않았다.
검사 보조 파일의 import 경로도 갱신했다. 수정 후 전체 검사 468개가 통과했다.
원래 검사 assertion을 유지했으며 실패를 숨기려고 검사를 삭제하거나 건너뛰지 않았다.

사용자는 커밋 후 게시글과 이미지 조회 검증을 별도 세션에 이관하도록 지시했다.
후속 작업은 실제 조회 검증이 통과한 뒤에만 작업용 이미지 보관본을 삭제한다.
이 커밋 단계에서는 이미지 보관본을 삭제하지 않는다.

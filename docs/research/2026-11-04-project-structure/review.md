# 구조 변경 독립 검토

최종 판정: 구조 변경에 남은 Important 문제가 없다.
검토자는 파일을 수정하지 않았으며 검사와 빌드를 실행하지 않았다. 실행 소유자는 구현 세션이다.

## 발견과 수정

1. 게시 workflow가 제거한 정적 콘텐츠를 요구했다. 배포 파일 바이트와 공개 API의 커밋, 글 ID, 본문 revision을 검사하도록 수정했다.
2. 과거 자산 도구가 이전 public 경로에 썼다. 생성 도구와 검사 도구를 app/web/public에 연결했다.
3. 명시적 정적 내보내기를 dist/static/content에 격리했다. 일반 Vite 빌드와 분리했다.
4. CategoryManager가 페이지의 drag hook을 가져왔다. hook을 같은 기능 폴더로 이동했다.
5. 이관 CLI의 자산 기본 경로가 남아 있었다. app/web/public으로 수정하고 실제 CLI 검사를 추가했다.

Git 없는 배포의 출처 검사와 정적 내보내기의 실패 주입 및 복구 검사를 보존했다.
카탈로그의 Git blob ID, 문서 참조와 메타데이터 검사도 유지한다.
Vite는 dist/web만 비우므로 dist/native를 보존한다. 루트 API 연결과 서버 목록 경로가 일치한다.

## 한계

동시에 들어온 스타일과 분류 수정의 소유자는 확인하지 못했다. 해당 수정은 되돌리지 않았다.
검토 판정은 구조 변경의 정확성에 한정한다. 화면 동일성을 승인한 결과가 아니다.
구현 세션은 이후 정적 내보내기 fixture의 부모 폴더 누락을 발견해 준비 코드에 추가했다.
기존 assertion과 실패 주입은 유지했다.

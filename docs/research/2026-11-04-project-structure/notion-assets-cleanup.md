# 중복 Notion 자산 제거

2026-11-04 후속 지시에 따라 공개 경로의 중복 자산을 제거했다.
기존 호환 자산 보존 결정은 이 기록과 갱신한 구조 기준으로 대체한다.

## 변경

- app/web/public/notion/assets의 파일 6,453개와 asset-map.json을 공개 경로에서 제거했다.
- dist/web/notion과 이전 dist/notion의 빌드 복사본도 제거했다.
- 콘텐츠 서브모듈의 글별 첨부파일은 변경하지 않았다.
- 복구본은 Git과 배포에서 제외되는 .tmp/notion-assets-cleanup에 보관했다. 영구 삭제는 하지 않았다.
- README, 폴더 구조 기준과 개발 안내를 현재 결정에 맞췄다.

## 검증

글 3,032개의 Markdown을 실제 링크 파서로 검사했다. 표지와 아이콘도 확인했다.
실제 /notion 참조는 0개였다. 문자열로 남은 1건은 잘못 닫힌 Markdown이라 이미지 참조로 해석되지 않는다.
해당 원문은 수정하지 않았다. 로컬 개인 초안 저장소는 직접 조회하지 않았다.
TypeScript, 관련 보호 검사와 격리한 Vite 빌드가 모두 통과했다.
관련 검사는 정식 콘텐츠에 대한 과거 도구의 쓰기 차단과 서버 목록 준비를 확인한다.
빌드 출력에 notion 폴더가 없음을 확인했다. 검증한 출력을 dist/web에 반영했다.
검증하는 동안 app 소스는 바뀌지 않았다. 콘텐츠 서브모듈 커밋과 작업 상태도 유지했다.
전체 검사는 이 자산 제거 작업에서 다시 실행하지 않았다.

실행 결과는 notion-assets-verification.json, 파일 수와 바이트는 notion-assets-result.json에 기록했다.
기존 구조 변경의 전체 검사 실패와 화면 비교 제한은 verification.md에 별도로 보존했다.
커밋과 운영 배포는 하지 않았다.

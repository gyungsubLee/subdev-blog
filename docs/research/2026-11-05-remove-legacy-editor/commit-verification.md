# 분리 커밋 검증

서버 저장·조회, 클라이언트 동기화, 편집기 제거를 세 커밋으로 나눴다. 단일 GitHub 요청 작업과 공통 버튼 스타일, native 앱 변경은 제외했다. 같은 파일의 변경은 스테이징한 버전과 작업 트리를 구분해 보존했다.

스테이징한 버전만 별도 폴더로 추출했다. 서버 검사 184개 중 182개가 통과했다. 나머지 2개는 추출 폴더에 콘텐츠 입력이 없어서 실패했다. 입력을 보충한 뒤 두 검사가 통과했다.

클라이언트·HTTP 검사 62개 중 59개가 통과했다. HTTP 검사 3개는 추출 폴더에 생성 카탈로그가 없어서 실패했다. 생성 입력을 보충한 뒤 해당 검사들이 통과했다. 코드와 제한은 바꾸지 않았다.

마지막 편집기·앱 흐름 검사 50개와 `tsc -b`가 통과했다. 각 커밋의 `git diff --cached --check`도 통과했다. 기존 경고와 JSDOM의 미지원 API 진단은 남아 있다. 이번 커밋 단계에서 전체 검사와 빌드는 반복하지 않았다. 이전 전체 검사의 시간 초과와 분리 검사 결과는 카테고리 후속 보고서에 기록했다.

검사 원시 로그와 추출 소스는 로컬 `.tmp/commit-split/`에 보관했다. 이전 보고서의 원시 로그도 로컬 작업 트리에 보관하며 커밋에서는 제외했다. 원격 푸시와 배포는 하지 않았다.

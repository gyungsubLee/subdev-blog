# Remaining save optimization implementation plan

**Goal:** Reduce the remaining save latency and transfer volume while preserving the approved UI, public JSON API, read performance, validation, conflict detection and recoverability.

**Architecture:** Keep public index/body files byte compatible. Encode the writer-only generation cache in a versioned gzip JSON envelope, reading both legacy and compressed caches. Upload independent large blobs with at most two workers, choosing the smaller lossless Git blob request encoding.

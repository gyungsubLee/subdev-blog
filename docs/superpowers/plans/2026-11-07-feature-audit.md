# 구현 기능 조사와 CRUD 검증 계획

**목표:** 현재 구현한 기능을 조사하고, CRUD 오류를 재현하여 수정한 뒤 근거를 리포트에 남긴다.

**설계 기준:** 기존 화면과 저장 계약을 유지한다. 각 영역의 기존 검사와 격리한 GitHub fixture를 재사용한다.

**완료 조건:** 기능 목록과 검사 근거를 연결한다. 재현한 결함에는 실패와 통과를 확인한 회귀 검사를 남긴다.
실행하지 못한 검사는 통과한 검사와 구분한다.

**유지 대상:** 현재 UI, 사용자 콘텐츠, 캐시, 지연 로딩, 중복 요청 방지, 저장 충돌 검사, 원자적 저장을 보존한다.

## 소유자와 검사 범위

- `server_crud`: `app/server/src`, `tests/server`. API, 인증, GitHub 저장, 카테고리 CRUD를 검사한다.
- `web_crud`: `app/web/src`, `tests/web`. 편집기, 초안, 작업 공간, 동기화, 탐색을 검사한다.
- `content_native`: `app/content`, `app/shared`, `app/native`, 콘텐츠와 네이티브 검사를 맡는다.
- 부모: HTTP 통합 검사, Chrome 검증, 빌드, 변경 검토와 최종 리포트를 맡는다.

각 에이전트는 자기 영역만 수정한다. 같은 검사 대상은 동시에 실행하지 않는다.
최초 격리 검사에서는 원격 GitHub에 실제 글을 쓰거나 지우지 않는다. 앱 코드의 커밋, 푸시와 배포는 실행하지 않는다.

현재 UI, 콘텐츠 원본과 기존 사용자 변경을 보존했다. 원격 변경과 배포는 실행하지 않았다.

현재 UI, 기존 콘텐츠와 사용자 변경을 보존한다. 테스트용 글·카테고리만 만들고 정리한다.

- [x] 실제 글·카테고리 CRUD와 전후 데이터 보존을 확인한다.
- [x] 네이티브 탐색·새로고침·다운로드·재실행을 확인한다.

[후속 최종 리포트](../../research/2026-11-07-feature-audit/live/README.md)에 실제 커밋과 검사 근거를 연결했다.
전체 Node 664개가 통과했다. 마지막 두 표시 조건 수정 뒤 관련 48개 검사와 빌드를 통과했다.
기존 원본 10,302개를 보존했고 추가 파일은 검사 영수증 6개뿐이다. 테스트 글·카테고리는 원본과 공개 목록에 없다.
기존 화면을 유지하며 실패 복구의 기존 버튼만 표시했다. Chrome·Native 로그아웃, 검사 탭·앱·서버 정리까지 확인했다.

- 앱 HEAD: `git rev-parse HEAD`로 최종 리포트에 기록한다.

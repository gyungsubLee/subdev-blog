# 블로그 디자인 근거

Claude 공식 글 목록의 정보 구조를 Second Brain에 적용한다. 원문과 화면의 픽셀 일치는 아직 검증하지 못했다.

- 확인일: 2026-10-22.
- 참조: https://claude.com/blog. 이 주소는 https://claude.com/resources/articles 로 이동한다.
- 확인한 구조: 제목과 설명, 대표 글, 검색, 필터, 글 개수, 글 카드, 더 보기.
- 확인한 자료: 공식 페이지의 검색 인덱스와 텍스트. 연결된 Chrome 도구는 시작 오류를 반환했다.
- 색상: 배경 `#f5f4ed`, 본문 `#292820`, 보조 본문 `#737168`, 강조 `#c96442`, 구분선 `#dcd9cd`.
- 글꼴: 제목은 Georgia와 Noto Serif KR, 본문은 시스템 글꼴, 코드는 시스템 고정폭 글꼴.
- 배치: 넓은 여백, 대표 글과 보조 글, 카테고리와 검색, 전체 글 목록.
- 그림: 원문 이미지를 우선한다. 이미지가 없으면 자체 문서 연결 그림을 사용한다.
- 내용: 수집한 글만 표시한다. 카테고리는 원문 상위 페이지 구조를 따른다.
- 접근성: 키보드 초점, 검색 라벨, 대비, 모바일 배치, 동작 줄이기를 적용한다.

화면 검증을 다시 실행할 때 대표 목록, 검색 결과, 긴 코드가 있는 글, 모바일 너비를 확인한다.
